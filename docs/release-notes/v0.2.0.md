A grave shows its owner's name only to players the server's player groups allow (D231). Everyone else sees "Grave".

With Mayor 0.7.0 or newer, a grave's name follows Mayor's rule for who may know whose it is: the owner always sees their own name; others see it with a shared circle, either side's bypass, or both standing in the grave's world group while the owner is online. Without Mayor, or if Mayor can't answer, everyone but the owner sees "Grave".

Upgrading from 0.1.3 is a jar swap. Install or update Mayor to 0.7.0 first for names to show to anyone but the owner.

## Tested

- Unit tests for the rule: the owner always sees their name, no groups means others see "Grave", groups that allow or refuse, and rules that fail.
- Bots on a throwaway Paper 26.3 server with Mayor 0.7.0 (Mayor's live suite with this jar, 94/94): real graves from planned deaths, and each bot saw the name or "Grave" as the rule says, with the owner in the same group, moved away, sharing a circle, offline, and in a circle-only world.
- Not yet seen in a real game client.
