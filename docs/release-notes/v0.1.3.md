A small fix for Rewild 0.3.0, which asks plugins for block areas to keep as well as whole chunks.

LanternGraves 0.1.2 refused that new question. Rewild 0.3.0 already treats the refusal as "no areas", so 0.1.2 keeps working, but 0.1.3 answers it properly: graves keep their whole chunk, so there are no areas to add.

No change to graves, or to which chunks are kept. Upgrading from 0.1.2 is a jar swap.

## Tested

- A new unit test: asked for areas, LanternGraves answers with none instead of an error.
- Rewild 0.3.0 with LanternGraves 0.1.2 on a throwaway Paper 26.3 server (Rewild's `test/lanterngraves.mjs`): a grave kept its chunk, `/rewild why` named it, and a scan still proposed a run. 0.1.3 differs from 0.1.2 only in that answer.
