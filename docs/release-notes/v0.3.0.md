Works with Posse 0.11.0 (formerly Mayor); the Mayor name is no longer recognized (D196, D292).

A grave shows its owner's name only to players the server's player groups allow (D231). Everyone else sees "Grave". That rule now comes from Posse's ReachService.

## What changed

- LanternGraves looks for the plugin `Posse` and its `com.extantape.posse.api.ReachService`. An old Mayor jar left on a server is ignored, so others see "Grave" until Posse is installed.
- With no Posse, or a Posse that can't answer, a grave still shows "Grave" to everyone but its owner.
- The soft dependency in `paper-plugin.yml` is now `Posse`. Posse 0.11.0 or newer is needed for names to show.

## Upgrading from 0.2.0

Install it together with Posse 0.11.0, after renaming Posse's permissions as its release notes say. Swap in `LanternGraves-0.3.0.jar` with the server stopped. Nothing in LanternGraves' own config changes.

Unit tests, including a Posse that throws. LanternGraves' own `basic` (20/20) and `rules` (29/29) suites on each version, with no Posse. The other suites (extras, hazards, crash, mvinv, griefprevention) weren't rerun.
